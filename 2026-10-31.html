Mistral 发布 Large 4 开源权重：“Le Chonk”可下载自托管了（10-29/30）

Mistral 10 月 29 日放出旗舰模型 Large 4（Le Chonk）的开源权重：约 1 万亿参数（每 token 激活 52B）、100 万 token 上下文、原生多模态（文本＋图像输入），权重已上 Hugging Face。Mistral 称其在 Artificial Analysis 的 Coding Agent Index 上得 48%、为开源模型最佳，Terminal-Bench 4.0 得分 41%；API 价 0.70/2.10 美元每百万 token。许可为改良 MIT：自用、商用免费，但拿它对外提供模型服务需另签协议；自托管门槛不低，标准版需 8 块 B300。HN 讨论达 1472 分。对你：开源阵营又一款可本地部署的旗舰编码模型，OXR 对比路线之外多了一个参照系；Kimi K3.1 Pro 的完整权重则在 11 月 4 日前发布，两者可对照看。

Cursor 市场上的 Claude Code 扩展被植入 SSH 后门：最多 5000 名开发者受影响（10-29/30）

10 月 29 日，Cursor 的 VS Code 扩展市场上出现被篡改的 Claude Code 扩展 2.1.313（另涉 2.1.312），在约 11 小时窗口（2:27–13:35 PT）内分发，Cursor 初估最多 5000 名用户受影响。安全厂商 Phorion 发现：被改的扩展在加载时即执行恶意代码，向用户 authorized_keys 写入攻击者 SSH 密钥（标记为 `svc-telemetry`）、建立反向 SSH 隧道并做跨平台持久化（macOS LaunchAgent、Linux cron、Windows 计划任务），还收集主机名、Git 邮箱与约 40 个含密钥的环境变量名。因恶意代码自身 bug，多数机器上开启 SSH 的步骤会失败，但密钥与持久化仍会留下。Anthropic 声明非自身系统被入侵、官方渠道版本不受影响；Cursor 已下架问题包并临时关闭整个扩展市场做审计与密钥轮换。对你：如果你在 Cursor 里用过 Claude Code 扩展，立即查 authorized_keys 有无 `svc-telemetry`、清掉残留脚本并轮换相关凭证——只更新扩展不够，卸载也清不掉持久化。

NVIDIA 发布 Nemotron 3.5 Transcribe：开源语音模型，一个 checkpoint 干四件事（10-28）
