智东西 10 月 20 日报道，DeepSeek 开源了其内部大规模云服务推理框架 DeepInfer 与生产级 token 编解码组件 deepseek-recipe（英文报道称 DeepInfer 为 Apache 2.0）。DeepInfer 集成了高性能算子与深度优化的推理引擎，支持分布式推理、推测解码、SWA Bounded Replay、结构化输出，可在英伟达与华为昇腾平台运行；官方称支撑 V4.1 Flash 高吞吐服务的单一集群日吞吐达 155 万亿 token、按谷价折算每卡每小时收入约 38 美元。deepseek-recipe 的处理逻辑与官方 API 完整对齐，意在让第三方部署获得与官方一致的 API 体验。需要打折看的是英文拆解指出的缺口：公开版尚未包含 KV-cache 管理、跨机分离推理阶段与多副本负载均衡等组件，且目前确认只跑自家 V4.1-Flash。对你做推理/网关选型最有价值的不是口号，是它把 Prefill 用小并行、Decode 用 Wide-EP（64–128 卡）这类真实生产配方写进了技术报告——这是可直接对照自家网关的工程样本。

ego lite 登陆 Windows 测试版：Claude Code、Codex、Cursor 共用一个已登录浏览器，多个 Agent 后台并行10-20

BlockBeats 10 月 20 日报道，AI Agent 专用浏览器 ego (lite) 推出 Windows 测试版（此前仅 macOS）：基于 Chromium，可一键导入 Chrome 的书签、扩展、Cookie 与登录状态，Agent 经 `ego-browser` Skill 直接操作已登录的 Gmail、X、企业后台等站点；每个 Agent 有独立 Space 工作区、可同时跑多个任务而不抢你正在用的标签页，验证码/付款环节你可随时接手。它还把页面压成精简结构（标出按钮、输入框）并允许 Agent 用一段 JavaScript 连续执行多步操作，以减少工具调用与 token 消耗，官方自报 4 项内部测试最高快 3.45 倍（对比对象为 Vercel 的 agent-browser，无第三方复测）。对你做 wechat-cli-bridge / 多模型 CLI 的启发很直接：「共享登录态 + 隔离工作区 + JS 批处理」正在成为 Agent 浏览器的标准形态，Windows 版落地后你本机就能试。

Browser Use 实测 5 款「让编程 Agent 操作浏览器」的工具：分数全在误差内，成本差 2.3 倍10-20 公开

据 Techfeed 转述 Browser Use 10 月 20 日发布的实测：用 Codex CLI 0.144.6 + GPT-6 Luna（medium reasoning）在 BU Bench V2.1 的 100 个任务上对比 Browser Harness、Playwright MCP、Chrome DevTools MCP、agent-browser 等工具——得分 56.3–61.0、完全解决率同为 9%–11%，统计上分不出高下；但中位成本从 Browser Harness 的 0.042 美元到 Chrome DevTools MCP 的 0.097 美元，相差约 2.3 倍，中位输入 token 也从 2.1M 拉开到 6.7M。作者推测 MCP 的工具描述开销是主因之一，但同为 CLI 的 agent-browser 也比 Browser Harness 多耗约 1.6 倍 token，说明不只是「CLI vs MCP」的问题。注意局限：每工具只跑一轮、只测 100/200 任务、用的是云浏览器而非你已登录的本机 Chrome。结论对你选型够用了：给 Agent 配浏览器工具时，先比 token 账单，别比跑分。

社区讨论（Hacker News / Reddit / 开发者社区）

▪ 「MCP 还是 CLI」之争有了新账本：工具描述本身就是每轮都在付的税：开发者社区本周热议的一篇实测把账算到了 token 级别——MCP 每轮调用都要带上全部工具定义（某 Safari MCP 为 84 个工具 × 约 95 token ≈ 每轮 7,986 token），而 CLI 路径只带一个 bash 定义、工具面只在首次列举时付一次；按 Claude Opus 无缓存价估算，1,000 轮会话的开销差可达上百美元，提示缓存能把差距缩小约一个数量级但抹不平。共识落点很实用：短会话 / 探索用 MCP，长会话 / 重复流程用 CLI，高频固定动作沉淀成 Skill。这与上面 Browser Use 的 2.3 倍成本差是同一件事的两面，也正是你做多模型 CLI 时该默认的设计取舍。
