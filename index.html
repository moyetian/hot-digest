OpenAI 拟 11 月 12 日切断 Cursor 的模型供应：SpaceX 收购的余波，下周四见分晓

SpaceX 以 600 亿美元全股票收购 Cursor（母公司 Anysphere），交易已于 8 月 14 日完成；8 月 28 日 OpenAI 通知 SpaceX，拟于 11 月 12 日终止向 Cursor 直接供应模型，理由是对 SpaceX 能否在条款内使用其技术“无法确信”，且不再向 Cursor 提供未来新模型。注意两点：① 11 月 12 日目前仍是 OpenAI 提议的日期、不是双方确认的最终日期，Cursor 也可能提前结束；② 影响有限——OpenAI 模型只占 Cursor 流量的约 5%，Anthropic、谷歌、Grok 不受影响；自带 API key 仍能在 Cursor 里用 OpenAI 的聊天模型，但 Tab、Auto、Cloud Agent 等功能不能指过去。对你：你主力是 Claude Code 与 Codex，基本不受影响；但这件事说明“模型可移植性”已是生产力工具的硬需求——以后选工具先看换模型要不要重搭工作流。
