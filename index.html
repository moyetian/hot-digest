Claude API 推出 message threads：Agent 长循环每轮只传新消息，首字延迟中位数降约 35%（11-05 宣布）

Anthropic 宣布 Claude Platform 的 message threads 进入公开测试：开发者在 Messages API 加入 thread 参数后，Agent 每一轮只需传送自上次请求以来的新消息，服务端保留对话上下文；官方数据称，大多数 Claude Code 用户默认开启后，50 万–100 万 token 的请求首字延迟（TTFT）中位数下降约 35%。注意：token 用量不变——Claude 每轮仍会读完整对话，省的是延迟、不是成本。对你：你每天跑的 Claude Code 长会话、判卷闭环这类多轮 Agent 任务会明显变快；这是服务端能力，不用你改配置，等它默认覆盖到你用的线路即可。
