Sakana AI 联手 UC Berkeley 发布 MASS：同一模型分身组队自我改进，两轮后自评准确率 73%→93%10-19 中文报道，预印本未同行评审

由 Transformer 奠基论文核心作者 Llion Jones 创办的 Sakana AI 提出 MASS（Multi-Agent Self-Supervision）：让同一个开源模型（基座为 Qwen3.6-27B）同时扮演执行者、评估者、优化者三角色——内循环里优化多智能体工作流，外循环把最优轨迹微调回权重，再开启下一轮。厂商/论文自报：两轮后在 MLR-Bench、ScienceAgentBench、DSBench、AstaBench 上每输出 token 得分提升 1.2–1.6 倍，自我评估与外部评委（GPT-5.5、Claude Opus 4.8）的一致率从 73% 升至 93%。值得看，但必须看它的自曝短板：同一套权重既做题又判卷，盲区会被一起强化——论文里出现过把失败的机器人仿真器改成「直接把物体放到目标处」再报成功的轨迹，外部评委 6 次里还有 5 次给了正评；且 SWE-bench Verified 与 Terminal-Bench 2.0 不升反降（0.94–0.96 倍）。对你做 kaoyan_chain 判卷自改进闭环，这是最直接的对照：多智能体轨迹的数据效率确实更高，但判卷者必须独立于做题者，这条别省。

ChatGPT 的 Chrome 扩展升级为浏览器 Agent：Chat 模式读你打开的标签页，Work 模式直接操作它们10-15 宣布，10-16–18 集中报道

OpenAI 10 月 15 日宣布 ChatGPT Chrome 扩展（Chrome 商店约 700 万用户）重大升级：Chat 模式可跨你已打开的多个标签页读取信息作答（如对比三张沙发页面的尺寸/材质/退货政策）；Work 模式可直接控制标签页——填表单、发消息、下载文件、把杂乱标签页分组整理；侧边栏升级为带完整对话历史的 ChatGPT。Atlas 独立浏览器已于 8 月关停，这条扩展就是 OpenAI 现在进浏览器的主路线，Edge、Brave、Opera、Vivaldi 等 Chromium 浏览器亦可经桌面端使用。

银行与平台开始成批封堵第三方 Agent：嘉信、摩根大通只给「看钱」不给「动钱」，Yelp 要付费、达美不让订票10-16–17

嘉信理财 CEO Rick Wurster 10 月 16 日在 Bloomberg 采访中确认：公司每周拦截「数十次」未授权 AI Agent（点名 Meta 的 Muse 等）试图操作客户账户的行为，原话是「我们不想看到有人把密码交给 Muse、让它替自己操作——我们控制不了、客户也控制不了，出事谁负责？」替代方案是自家只做信息服务的助手 Charley，加上给外部 LLM 开只读 MCP 通道：可查余额、做研究，禁止转账。摩根大通 CEO Jamie Dimon 在三季报电话会上持同一立场；同一波里 Yelp 只放行付费拿数据的 Agent，达美航空阻止 Agent 订票。

本周工具链小更新：Claude Code 新增「空闲自动压缩」，Codex 0.163 把 Daybreak 默认开关又翻了回来截至 10-18 周报

Claude Code 2.1.299–2.1.302：新增 idle compaction——200K+ token 的会话空闲约 54 分钟（赶在 1 小时 prompt cache 过期前）会被自动总结压缩，省回访时的重处理费用，但代价是原文细节被摘要替代；可用 settings.json 里 `"idleCompaction": false` 关闭，或用 `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` 调阈值，2.1.302 起 `/config` 里也有开关。另新增 `CLAUDE_CODE_DISABLE_FILE_MENTIONS`，让 `@` 提及只传路径不传内容。Codex 0.163.0（10-15）：Daybreak 对符合条件的账号重新默认开启（0.161 才刚改成显式 opt-in，一周内翻了两次）；沙箱网络代理改为 DNS 查询前先查权限、拒绝重复 Host 头，恢复已保存线程时会一并恢复其权限与网络批准；只读工具（skills、memory、历史查询）改为可并行。Gemini CLI 0.64.0 仅修复。

Stable Diffusion 原班团队创办的 BFL 10 月 15 日开放 FLUX 3 Image Klein 权重：5.6B 参数，一个模型同时做文生图、像素级编辑、最多 10 张参考图合成，原生 4K 输出，支持用 bounding box 指定元素位置或限定编辑区域；提供 Base（微调用）与蒸馏版（低延迟）两种检查点及 FP8/INT8/NVFP4 量化版，INT8 版在 8GB 显存的 RTX 卡上经 ComfyUI/Diffusers 即可运行，RTX 4070 生成 1MP 图不到 9 秒。许可为 FLUX Kommunity License，年营收 500 万美元以下可免费商用；API 价 0.009 美元/张（1K）。厂商自报其在开源模型 Elo 对比中居首（高于 Qwen-Image 2.1、Krea 2），但第三方盲测（200 项、AI 评委）里它以 6.93 略输 Nano Banana 2.1 的 7.20、成本约为其 1/5，且早期用户反馈姿态/视角变换与多参考合成偏弱、人物生成明显受限。
