小模型价格战的账算清了：短请求美方更便宜，重度缓存复用反而是 DeepSeek 更省10-10 长文复盘

新浪科技转 AIX 财经的测算把三家小模型放在同一口径下比：Claude Haiku 5.5 与 GPT-6 Luna 同价（10 万 token 内输入 0.10 / 输出 0.50 美元每百万 token），裸价已低于 DeepSeek-V4.1-Flash；但 DeepSeek 在 100 万 token 内统一计价、缓存价 0.003 美元低于 Haiku 的 0.01 美元。用一份 4 万 token 文档反复追问的例子算：第一轮 Claude 略便宜，第二轮起每轮 DeepSeek 更便宜，几轮就追平。同日 Anthropic 还把 Sonnet 5.5 的缓存读取价从 0.20 砍到 0.10 美元——砍的正是 Agent 账单里占比最大的缓存读取。

值得看给 kaoyan_chain 选模型要分两种账：一次性短问看裸价，把同一份材料当知识库反复查则看缓存价。

⚠️ 安全关键：编程 Agent 的 hooks 默认"失败放行"，Claude Code v2.1.295 新增 `onFailure: "block"`10-08 发布、10-09 实测对比

Developers Digest 实测对比四家：Claude Code、Cursor、Gemini CLI 的守卫脚本一旦崩溃、超时或无法启动，默认都会放行工具调用；v2.1.294 先修了"写成自然语言指令的 hook 反而放行该拦的命令"，v2.1.295 再给命令与 HTTP hooks 加上 fail-closed 开关。Cursor 早有 `failClosed: true`；Codex 文档中暂无同类开关，其已记录的失败路径是继续执行，只能靠沙箱与审批策略兜底。

QIQCBench：17 家顶级 Agent 进真实量子科研流程，通过率从 78% 断崖跌到 3%近 1 日报道

这套新评测把 GPT、Claude、DeepSeek、千问、GLM 等 17 个 Agent 系统放进真实量子实验工作流，不只看最终答案，而是用"证据绑定"评分：核查结论是否真由执行记录中的数据支撑、逻辑是否自洽，并把方案扔到隐藏数据集上重跑验证。结果是通过率跨度极大；总计 1510 次失败里有 937 次是陷入死循环或耗尽预算没能交卷，剩下的失败中过半是结论经不起交叉验证。
