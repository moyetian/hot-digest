Cursor 市场上的 Claude Code 扩展被投毒：2.1.312 / 2.1.313 含 SSH 后门，最多影响 5000 用户（10-29/30）

Cursor 官方安全通告：10 月 29 日 2:27 至 13:35（太平洋时间），其 VS Code 扩展市场分发了被篡改的 Anthropic.claude-code 2.1.312 与 2.1.313，冒用真实发布者身份、经自动更新推送，估计最多 5000 名用户中招。篡改版在合法代码前插入 66 行加载器，会收集主机名、用户名、环境变量名、Git 邮箱、公网 IP，并把攻击者的 Ed25519 密钥（标签 `svc-telemetry`）写入 `~/.ssh/authorized_keys`、尝试建立反向 SSH 隧道。Cursor 已下架问题版本、关闭市场排查、轮换密钥，干净版本为 2.1.314；Anthropic 称自身系统未被入侵，微软确认该包未流入 VS Code Marketplace、Open VSX 或 npm。对你：如果你在 Cursor 里装过 Claude Code 扩展，检查是否在上述时间段装过 2.1.312/313，并查 `authorized_keys` 里有无 `svc-telemetry` 密钥；这也是扩展市场供应链攻击的典型案例。
