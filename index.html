Claude Code 新规：禁止用其复刻现有游戏（10-30 更新，11-02 报道）

Anthropic 更新 Claude Code 使用规则，明确禁止用户借助 Claude 复刻现有游戏，措辞是：“可以制作原创游戏、某一类型的游戏，以及基于用户自己的设计和素材制作的游戏。不要制作对某一款现有游戏的重制，即使它被改名或被称为原创也不行。”技术团队成员 Addy Osmani 在 X 上确认，团队在 Opus 5.5 的 Claude Code 提示词中加了两句话引导它拒绝复刻他人具体游戏，原因是“用 Claude 侵犯知识产权违反使用政策”；原创游戏、类型游戏与基于用户自有设计素材的作品仍可正常生成。对你：这是 Claude Code 首次在游戏克隆上收紧口径，之前拿它“复刻个某某游戏练手”的玩法会被挡；做原创小游戏不受影响。

Claude Code 2.1.316：Opus 4.8 fast mode 11 月 30 日移除，空闲压缩扩展到 VS Code 与桌面端（11-01 周报）

本周 Claude Code 连发 2.1.311、2.1.312、2.1.314、2.1.316 四个版本。关键变化：Opus 4.8 的 fast mode 已于 10 月 30 日弃用、11 月 30 日正式移除，移除后 fast mode 请求会直接报错、不会回退到标准 Opus 4.8，官方建议 11 月内迁到 Opus 5.5 保住加速；idle compaction（空闲压缩）从终端扩展到 VS Code 与桌面端 Code 标签，20 万 token 以上的长对话闲置后会自动摘要；新增 `permissions.blockWritesOutsideWorkingDirectories`，Write/Edit 拒绝写工作目录外的路径。对你：如果你在配置里写死了 Opus 4.8 fast mode，这个月内改掉，否则 11 月 30 日后会报错；新权限开关对防误删写盘外文件有用。
