Simon Willison 与 Prime Radiant 发布 Agent 外部沙箱三件套（11-17）

Agent 跑在本机、执行的代码进沙箱：三个实现共用同一 localhost API——external-sandbox-v86（WebAssembly 里跑 Alpine Linux）、external-sandbox-container（Apple Containers）、external-sandbox-quicksand（QEMU + 微软 Quicksand），Claude Code、Codex、Pi 都能把代码执行接进去；附带 HTTP 白名单代理与凭证替换机制，联网权限和密钥都不必交给 Agent。但注意一个缺口：Claude Code 目前只有 Bash 工具进了沙箱，原生 Read/Edit 还留在宿主机上，所以不算完整隔离；三者仍是实验原型、未经审计。对你：你在笔记本上跑 Agent 时最怕的就是提示注入后乱动文件，这个模式正是冲着这个问题来的——可以先看，不急着上生产。
