安谋科技发布 Cortex-M42 与“星辰 100e”AIoT 原型平台（11-18）

安谋科技（中国）在 Arm Cortex-M CPU 新品说明会上解析 Arm Cortex-M42 处理器，并推出基于该 CPU 的“星辰 100e”AIoT 原型平台。Cortex-M42 基于 Armv8.1-M 架构，面向成本和面积敏感的低功耗智能端点，打包 Helium 矢量扩展与 Arm 自定义指令；平台走 CPU 加专用 NPU 的异构路线（Cortex-M42 + Ethos-U55），已在 FPGA 上跑通关键字检测、目标识别、自动语音识别等用例，实测相比单独使用 Cortex-M42，关键字检测推理性能提升 95 倍、目标识别提升超 132 倍、自动语音识别提升超 340 倍。对你：这是 MCU 级端侧 AI 的新底座，SmartVocab 以后如果要做离线语音/低功耗端侧功能，这条“CPU + microNPU”路线比手机 SoC 更贴近嵌入式；提醒一句：这是 FPGA 原型平台的实测倍数，不是量产芯片成绩。
