Claude Duet 研究预览细节补齐：发信、付款、删除前必须停下问你，证券买卖连批了也不做（10-21 发布，本周细节发酵）

Anthropic 的常驻个人 Agent Duet 以 Opus 5.5 为内核、独立应用 + 专属云端虚拟机，可归纳日程、追踪应用消息、离线持续执行。本周披露的审批细节是关键：发消息、付款、签名、删除前必须出示执行内容等用户批准；证券买卖与账户间转账即使批准也不执行；信用卡号、政府 ID 类请求由新分类器直接拒绝；健康、个人财务信息只有明确指示发送时才放行。限制同样实在：现阶段只面向美国地区 Claude Pro / Max 用户候补开放，国内暂无时间表；后台定期检查计入同一套 Claude 额度，大任务更耗额度；官方自承早期版本可能误读邮件线程、误判紧急程度，个人琐事能力弱于工作任务。对你：这是你做 Agent「打扰预算」与审批分级最现成的参照系——「必须批、批了也不做、直接拒绝」三档划分，比一刀切的弹窗更值得抄；但 Duet 本人你目前用不上，不必找渠道抢号。
