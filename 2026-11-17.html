三家 CLI 本周齐发版：Claude Code v2.1.321–325、Codex 0.167.1–0.169.0、Gemini CLI v0.68.0（11-14 周报）

Claude Code 连发四版：v2.1.321 修了 4 处权限与沙箱缺口，v2.1.325 修了 zstd 解码安全问题；v2.1.323 新增实验性 Code Mode（让 Claude 写 JS 来调工具），Fable 5.2 成为默认 Fable 模型（1M 上下文，$8/$40 每百万 token，缓存读 $0.20）。Codex 连发四版：v0.169.0 收紧 `codex exec` 的信任判定，`--sandbox workspace-write` 不再自动启用项目配置与 MCP；另有多 side-chat 标签页、可搜索历史任务。Gemini CLI v0.68.0 以沙箱与路径修复为主。对你：先把 Claude Code 升到 v2.1.321 以上（权限与安全修复是实打实的）；Codex 的信任收紧可能影响你自动化脚本里 MCP 的启用方式，升级后检查一次；Code Mode 还是实验功能，先观望。
