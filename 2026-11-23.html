Claude Code v2.1.328 自动模式扩到第三方平台；Codex 0.171.0 把 GPT-6.2 Sol 设为默认模型（11 月 22 日当周）

本周 CLI 三家的新版本：Claude Code v2.1.328 把 auto 模式带到 Amazon Bedrock、Google Cloud Agent Platform、Microsoft Foundry 与 Claude apps gateway，且无权限模式的交互会话默认就从 auto 模式启动——走第三方平台的话，弹确认的频率会变，不用改设置也会变；Codex v0.171.0 把 GPT-6.2 Sol 设为模型目录默认选择，并把 TUI 工作区（可搜索文档预览、图片预览、子智能体记录）默认开启；Gemini CLI v0.69.0/v0.70.0 集中修了 shell 命令审批与权限策略匹配。另注意上周的收紧仍在生效：Claude Code 2.1.325 起沙箱内 Bash 默认走常规权限确认（想恢复自动放行需显式设 `sandbox.autoAllowBashIfSandboxed: true`），Codex 0.169.0 起 `codex exec` 在未信任目录默认禁用项目配置与 MCP（需 `--trust`）。对你：你主力是 CodeBuddy 与 Qoder，Claude Code/Codex 不是日常工具，但这波“默认收紧权限＋默认开自动模式”是整个 Agent CLI 行业的方向——以后你给 kaoyan_chain 写无人值守脚本时，默认行为变了要先查版本，别按旧习惯写。
