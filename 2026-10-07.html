Claude Code 推出 mods：内建功能可被用户替换，核心走向"小核心 + 插件"10-01/02 官宣

Anthropic 为 Claude Code 推出 mods 机制：几行 TypeScript 即可改写行为、重绘界面、拦截工具调用、甚至整个替换内建功能（官方 `/diff` 已率先改成 mod）；mods 随插件分发、无沙盒、权限等同 Claude Code 本身；官方表示未来会把更多内建功能改成 mod。
