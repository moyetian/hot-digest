Claude Code 2.1.326 发布，Code Mode 正式官宣（11-16/17）

Claude Code 2.1.326（11 月 16 日）启动时会警告写残的 `--allowedTools` / `--disallowedTools` / `--tools` 规则，Code Mode 现在可与 agent teams 联用；Anthropic 官方账号 11 月 17 日正式介绍实验性 Code Mode：开启后 Claude 直接写 JavaScript 来调工具，而不是逐条发 JSON 工具调用，需 `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1` opt-in，v2.1.323+ 可用、与 teams 联用需 v2.1.326+，且仅限交互式终端会话。另注意 2.1.325 的行为变化：沙箱内 Bash 默认走正常权限流程，`/loop` 与定时任务跑带 `allowed-tools` 的 skill 前会先问你。对你：先把 Claude Code 升到 2.1.326——权限警告能帮你提前发现写坏的规则；Code Mode 还是实验功能，先观望，别在判卷回归的主力会话里开。
